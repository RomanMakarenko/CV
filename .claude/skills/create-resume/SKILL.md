## 4. Візуальне оформлення

### Загальні правила:
- **Розмір:** 1 сторінка (максимум 2, якщо дуже важлива інформація)
- **Шрифти:** використовуй Google Fonts (Inter, Roboto, Lato, Montserrat — один шрифт на все резюме)
- **Кольори:** єдина кольорова схема (максимум 2 кольори + чорний/сірий)
- **Вирівнювання:** по лівому краю
- **Один стовпець:** не використовуй два стовпці
- **Відступи:** достатньо повітря між секціями
- **Формат:** HTML для перегляду в браузері та друку в PDF

### Стильове оформлення кожного шаблону:

#### Професійний
- Колірна схема: темно-синій (#1a237e) + сірий
- Чіткі лінії-роздільники між секціями
- Жирний шрифт для заголовків
- Компактні відступи

#### Хроно
- Колірна схема: темно-зелений (#1b5e20) + світло-сірий
- Дата ліворуч, опис праворуч (але в HTML це один потік)
- Таймлайн-лінія з точками для кожного періоду
- Акорд на прогресії кар'єри

#### Елегантний
- Колірна схема: індиго (#3f51b5) або фіолетовий (#5e35b1) + світлі відтінки
- Мінімалістичний, великі проміжки
- Тонкі border-bottom замість ліній
- Гарний letter-spacing для заголовків

#### Круглий
- Колірна схема: теплий (#e65100) або бірюзовий (#00695c) + акцент
- Rounded cards для кожної секції (border-radius, soft shadow)
- Кругові індикатори для рівня навичок (SVG circles)
- Аватар/фото-місце (ініціали в крузі)

## 5. Технічна реалізація

Згенеруй єдиний self-contained HTML-файл з:

1. **Inline CSS** (в `<style>`) — всі стилі всередині, без зовнішніх залежностей крім Google Fonts
2. **Google Fonts** підключи через `<link>` в `<head>`
3. **@media print** — резюме має чудово виглядати при друці:
   ```css
   @media print {
     @page { margin: 0.5in; size: A4 portrait; }
     body { -webkit-print-color-adjust: exact; print-color-adjust: exact; }
   }
   ```
4. **Адаптивність** — резюме має виглядати добре на екрані та при друці
5. **Іконки** — використовуй SVG або Unicode-символи замість Font Awesome (щоб не завантажувати додаткові бібліотеки)

### Оптимізація для друку:
- `page-break-after: avoid` для секцій
- `page-break-inside: avoid` для блоків досвіду
- Кольори мають друкуватися (`print-color-adjust: exact`)
- A4 формат

## 8. Edge Cases

| Ситуація | Дія |
|----------|-----|
| Дані неповні | Використай що є, познач відсутні секції коментарем в HTML |
| Користувач хоче всі стилі | Згенеруй всі 4 файли одночасно |

| Потрібен текстовий export | HTML-версія — завжди, додатково можна створити .txt/.md версію |
| Потрібна англійська версія | Переклади весь вміст на англійську, збережи файл з `_en` суфіксом |
